# Paridad Android y Mac · Fase 3, subproyecto 2

La columna de Android está verificada. La de Mac se completa al unir la rama de Mac («ver rama Mac» donde aún no se conoce).

| Función | Android | Mac |
|---|---|---|
| Agregar fotos sueltas | Editor › Fotos › «Agregar» (selector del sistema) | ver rama Mac |
| Agregar una carpeta de fotos | Editor › Fotos › «Agregar carpeta» (selector de carpetas; nivel superior, por nombre, tope 500; avisa «N fotos agregadas · M archivos ignorados») | ver rama Mac |
| Buscar diseños | Catálogo y «Cambiar diseño»: campo arriba de las categorías; sin acentos ni mayúsculas, nombre y descripción; estado vacío con «Ver todos» | ver rama Mac |
| Margen en las unidades elegidas | Editor › Papel › «Margen de la hoja» (mm o pulgadas según Ajustes) | Editor › Papel › «Margen» (unidad de preferencias) |
| Papel predeterminado, 8 tamaños | Ajustes › «Papel para diseños nuevos» | Preferencias › «Papel para nuevos diseños» |
| Borde de las tarjetas | Editor › Papel, visible junto al margen | Editor › Papel › «Imprimir borde de las tarjetas» |
| Rehacer | Barra del editor (≥ 400 dp y letra ≤ 1.15); si no, en ⋮ | ver rama Mac |
| Imprimir | Barra del editor, botón con ícono y texto «Imprimir» | ver rama Mac |
| Quitar fondo | Menú de la tarjeta (acción directa que abre Encuadrar en la sección de fondo) y Encuadrar › «Fondo de la foto» | ver rama Mac |
| Sección «Canción» (título, artista, enlace del QR) | Editor › Texto, primera sección en diseños musicales; el enlace solo en «Foto + canción», que es el único que imprime QR | ver rama Mac |
| «Mostrar este texto» y «Tamaño» (Auto/Chica/Mediana/Grande y exacto) | Editor › Texto, a la vista | ver rama Mac |
| Posición, desplazamiento y alineación | Editor › Texto › «Más opciones» | ver rama Mac |
| Navegar entre hojas con gestos | Botones ‹ › del editor | Dos dedos en el trackpad y flechas ← → (rama Mac) |
| Fuentes del sistema | No disponible: Android no puede enumerarlas de forma fiable | Disponible; un proyecto con una fuente de sistema se abre en Android con Gelasio de respaldo |
| «Usar mi molde» en un proyecto existente | Pendiente del subproyecto 3 | Pendiente del subproyecto 3 |
