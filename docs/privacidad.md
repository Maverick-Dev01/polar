# Política de privacidad de Polar

**Última actualización:** 2 de octubre de 2026

Polar es una app para diseñar e imprimir tus fotos. Diseñar, guardar e imprimir funciona sin internet; no tiene cuentas ni anuncios.

- **Qué datos usa:** sólo las fotos y plantillas que tú eliges. Polar hace una copia dentro de la app para que tu diseño no se pierda; tus originales no se modifican.
- **Dónde quedan:** en tu teléfono. Polar no envía tus fotos ni diseños a servidores.
- **Actualizaciones:** la versión de GitHub consulta y descarga archivos públicos desde GitHub sólo cuando lo solicitas en Ajustes. Como cualquier conexión HTTPS, GitHub recibe la dirección IP y datos técnicos de la petición; no se envían fotos, diseños, nombres de proyecto ni identificadores propios del usuario. No hay analítica. [Privacidad de GitHub](https://docs.github.com/es/site-policy/privacy-policies/github-general-privacy-statement). La versión Play utiliza las actualizaciones de Google Play.
- **Qué compartes tú:** cuando eliges Imprimir, Guardar o Compartir, el archivo va sólo a la impresora, carpeta o app que tú selecciones.
- **Permisos:** Polar usa el selector de fotos y el selector de archivos del sistema; no pide acceso a toda tu galería ni a tu almacenamiento. La versión GitHub tiene acceso a internet para actualizar y puede pedir permiso para abrir el instalador; Android exige confirmar la instalación.
- **Borrar tus datos:** borra un diseño desde Tus diseños, o desinstala la app para eliminar todo.
- **Niños:** Polar no recopila datos de nadie, incluidos menores.
